escalation-triage-agent: coordinator → specialist

Two-role handoff demo. The specialist can only read runbooks through MCP. The coordinator keeps the proposal. Only a human can approve a write.
THE HANDOFF LOOP
1. Question inCoordinator receives the question or a proposal request.
2. HandoffDelegate to the runbook specialist. Budget: two messages (out and back).
3. Specialist (MCP-only)May call search_runbooks and cited_runbook_answer only. Returns citations. Stops. Never proposes.

KEY IDEAS TO UNDERSTAND
Handoff budget
Two messages max. A smaller budget stops with MAX_HANDOFFS before any write.
Read-only specialist
Cannot approve or log actions. Citations only. Coordinator owns the proposal.
Human owns the write
propose_action always returns pending. Only human_said_yes becomes True.
Offline by default
handoff.py and mcp_server.py need no API key. Practice fixtures only.
