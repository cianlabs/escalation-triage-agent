## Review of the old set

Seven original events remain with corrected observations and labels. The old AWS URL actually describes November 25, 2020 Kinesis thread exhaustion, so it is included under its correct incident and date. CircleCI was omitted because its security report did not support the invented worker-memory story. The cited OpenAI and Heroku pages returned 200 without report text and were omitted. The Reddit mirror was omitted under the first-party-only selection rule. Detailed decisions are in incidents/original_source_audit.json.

The old synthetic records and historical INC-prefixed CLI ids remain available for workflow testing in fixtures/synthetic.json. Their logs and deploy records are fiction, not reconstructed public evidence. They are excluded from every public metric.

## Practice runbooks

The six files in runbooks are simplified synthetic workflow prompts, not verified operational procedures. They are used by the CLI tests, but public ranking evaluation does not search them. Their old source claims are withdrawn: a general documentation page does not establish that a restart or rollback is the correct response. Never use those prompts as production instructions.

Run python verify_sources.py for an online reachability and section check. A person must still read changed pages to check meaning. Offline CI checks dataset integrity and reproduces the baseline, rather than depending on website availability.
